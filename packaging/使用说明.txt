设计台 · 使用说明（Mac 和 Windows 通用）

一、第一次使用
1. 先把压缩包“全部解压”（Windows：右键压缩包 → 全部解压缩；Mac：双击压缩包）。
   不要直接在压缩包里双击运行。解压出来的“设计台”文件夹可以放在任何地方，比如“文档”里。
2. 打开“设计台”文件夹：
   · Windows：双击“启动设计台.bat”。
     如果弹出“Windows 已保护你的电脑”，点“更多信息”→“仍要运行”。
     第一次启动后，桌面上会多一个“设计台”快捷方式，以后双击它就行。
   · Mac：右键点“启动设计台.command”，选“打开”，再点一次“打开”。
     如果提示“Apple 无法验证”，到 系统设置 → 隐私与安全性，往下找到它，点“仍要打开”。
3. 浏览器会自动打开 http://127.0.0.1:4180 ，这就是设计台。
   这个地址只在你自己的电脑上有效，不需要联网也能打开。

二、关掉设计台
双击“停止设计台”（Windows 是 .bat，Mac 是 .command）。不停也没关系，关机后会自动停止。

三、数据在哪
所有项目、资产、稿件都在“文档/设计台数据”文件夹里（Windows 是“文档”，Mac 是“文稿”）。
换电脑时，把“设计台”文件夹和“设计台数据”文件夹一起拷过去就能接着用。
更新设计台时只替换“设计台”文件夹，数据不会丢。

四、AI 功能（可选）
不配置也能用。想让 AI 识别需求、发散脑图、看图评审，在左下角“设置 → 模型与密钥”里粘贴千问（DashScope）的 API Key。
密钥只存在这台电脑上。AI 功能需要联网，没网时会自动换成本地规则。

五、左边导航
· 全部项目、资产库在最上面。
· “项目”旁边的 ＋ 新建项目；点开一个项目，会展开 6 个步骤：需求 → 创意发散 → 视觉风格 → 出稿 → 评审 → 交付。
· 最下面是设置：深色 / 浅色、评审角色、品牌规则、模型与密钥。
